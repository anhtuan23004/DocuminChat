# Hermes WebUI reference

The original prototype's interaction principles draw from [Hermes WebUI](https://github.com/nesquena/hermes-webui),
commit `9e380c2da93463c813cb58dd57f11b75a21626b2`, especially `DESIGN.md`,
`docs/UIUX-GUIDE.md`, and `static/style.css` / `static/index.html`.
DocuminChat's HTML/CSS/JS is implemented separately; upstream runtime is not bundled.

The current shell uses DocuminChat components and follows usability patterns
studied in official ChatGPT Projects documentation. OpenAI screenshots are
research references only and are not shipped as application assets.
